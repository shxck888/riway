專案背景與目標

天使團隊需要一套完整的數位化獎勵計畫平台，以點數與激勵機制提升成員參與度，並提供透明、易用的禮品兌換流程。本提案涵蓋完整的 UI/UX 設計、前端介面、後端 API、資料庫架構及會員身份驗證系統，從設計到部署一次交付。前端採 React 或 Vue 搭配 TypeScript 開發（框架於需求確認後定案）；後端以 TypeScript 為主體實作 RESTful API，資料庫為 PostgreSQL。

專案名稱
天使團隊獎勵計畫平台

繁體中文介面
使用對象
一般會員 · 系統管理者
適用裝置
桌機 · 平板 · 手機（響應式）
前端技術棧
React 或 Vue + TypeScript
後端技術棧
TypeScript · RESTful API · PostgreSQL · JWT

功能模組說明

本系統分為設計、會員端、管理端、系統基礎四大類，共 20 個功能模組，為完整規劃藍圖。核心流程（如登入、點數、簽到、兌換、審核等）優先開發與驗收；部分進階功能（如排行榜、任務／挑戰中心、報表匯出、系統設定、會議／日程行事曆與 .ics 等）則依開發優先順序滾動調整排程，由雙方於各階段確認里程碑，並於專案週期內逐步交付。

    採 Google Cloud Platform，含 Cloud Run、Cloud SQL 等高可用性配置。實際雲端資源費用得視流量、儲存與備份保留等用量浮動，於維運合約中約定定額內含範圍或超出部分之處理方式（如實支實付或加價級距）。

    技術維運與安全保障（勞務）
    • 每日自動備份：資料庫定期備份，降低點數帳本等資料遺失風險（還原演練範圍依合約約定）。
    • 安全監控與防護：監控異常登入、協助基本惡意攻擊防護設定，並維持 SSL／HTTPS 憑證有效。
    • 故障即時處理（SLA）：可歸責於系統或乙方設定之異常，於營業時間內 4 小時內回應並開始處理（「回應並開始處理」不等同保證當日完全修復；不含第三方雲端全面故障、客戶自行變更 DNS／設定等不可歸責事由；營業日與時段於維運合約載明）。
    數據與諮詢服務（專業）
    • 每月數據報告：彙整當月點數發放概況、熱門兌換禮品等營運指標（以系統既有資料為準），協助甲方決策。
